# Labels for customer emails

Each customer email gets exactly one label.

| Label | Use it when |
| --- | --- |
| Order issue | The question is about an order: its status, a delay, a missing package, a change to the address. |
| Return request | The customer wants to send an item back or asks how returns work. |
| Billing | The question is about money: a charge, a double charge, a refund that has not arrived, an invoice. |

The five emails are in `emails/classify-five-emails.txt`.
